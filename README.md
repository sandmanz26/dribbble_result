# Co-Ware, co-warehousing website prototype

React 18, Vite 5, HashRouter, css.gg icons (`react-icons/cg`), Unbounded + Outfit (Fontsource), no
animation library. No backend and no storage.

```bash
npm ci && npm run dev
npm run build   # dist/
```

Routes: `#/` home (floor plan at `#plan`), `#/spaces/shelf|pallet|bay|desk`, `#/tour?unit=B2`.
Photos in `public/img/` are AI-generated concept images (Higgsfield). Prices, units and dates are samples.
Strategy: `docs/strategy.md`.
