# Cooperative app redesign (Arabic and English)

Prototype for the "Cooperative Mobile Redesign AR/EN Figma" brief. React 18, Vite 5, HashRouter,
Material icons (`react-icons/md`), Alexandria (Fontsource). No backend; state in localStorage
(`coop-state-v1`).

```bash
npm ci && npm run dev
npm run build   # dist/
```

Routes: `#/` home, `#/search`, `#/c/fresh`, `#/p/dates`, `#/lists/home`, `#/assistant`, `#/cart`,
`#/member`, `#/audit`, `#/ia`, `#/system`. Strategy and research: `docs/strategy.md`.
Product pictures in `public/p/` are AI-generated packshots (Higgsfield). Co-op names, people and prices
are samples.
