# Skill-to-Research Bridge (project15)

Landing page and clickable app for a platform that matches university students' demonstrated skills to research
projects. React 18, Vite 5, HashRouter, Atkinson Hyperlegible Next, Octicons. State in `brg-state-v1`.

Routes: `#/` landing · `#/app` student home · `#/app/projects/bus-stop-heat` readiness worked out · `#/app/evidence`
· `#/app/passport` · `#/app/privacy` · `#/lab` researcher home · `#/lab/applicants` · `#/lab/verify` ·
`#/p/BRG-7Q4-LH2` public passport. Notes: `docs/strategy.md`.

    npm ci && npm run build   # outputs dist/
