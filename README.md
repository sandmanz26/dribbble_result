# Darb Logistics (project14)

Bilingual Arabic/English website prototype for a Saudi shipping and logistics company. React 18, Vite 5, HashRouter,
Readex Pro, Solar icons. Arabic first (RTL), English mirror; language stored in `darb-lang-v1`, quotes in
`darb-quotes-v1`. Open any page in a language with `?lang=en` or `?lang=ar`.

Demo tracking numbers: DRB-240117 (on the road), DRB-240233 (held for a document), DRB-239981 (delivered).
Developer handoff: `#/handoff`. Notes: `docs/strategy.md`. Photos: Open Images, CC BY 2.0, credited at `#/credits`.

    npm ci && npm run build   # outputs dist/
