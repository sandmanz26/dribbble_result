# Westpoint case study (project6)

Private case study page: a web ERP plus driver and passenger apps for a charter bus company.
The page is a single self-contained `index.html` (images inlined, no scripts), served as-is.

It is hosted here because Dribbble limits which domains a proposal can link to. It is password
gated on the hub (`main`) and marked noindex. Do not edit the copy here without the owner; the
original lives on the owner's website.

```bash
npm ci
npm run build   # copies index.html to dist/
```
